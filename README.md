# LoL Pick Coach

리그 오브 레전드 챔피언 선택과 게임 중 빌드를 돕는 Windows 앱입니다.

## 다운로드

**[최신 버전 다운로드](https://github.com/Ohjjam/LoLPickCoach/releases/latest/download/LoLPickCoach-Windows.zip)**

처음 한 번 ZIP을 내려받아 폴더에 압축을 풀고 `LoLPickCoach.exe`를 실행하세요. `_internal` 폴더를 함께 유지해야 합니다. GitHub 로그인이나 Python 설치는 필요하지 않습니다.

v0.6.4부터 새 버전을 앱에서 자동으로 준비합니다. 다음 실행 때 적용되며, 상단 **업데이트 후 재시작** 버튼으로 바로 적용할 수도 있습니다. 게임·챔피언 선택 중에는 업데이트 준비와 재시작을 미룹니다. 배포 서명과 파일 무결성을 확인하고, 새 버전 시작에 실패하면 기존 앱을 유지합니다. 설정과 챔피언 풀도 보존합니다.

v0.6.3 이하 사용자는 자동 업데이트 기능이 들어 있는 버전을 처음 한 번 받아야 합니다. 이후 원래 받은 실행 파일을 계속 사용하면 됩니다.

## 기능과 범위

- 양 팀 조합·상성을 참고하는 챔피언 추천과 자동 맞상대 추정
- 선택 단계의 룬·스펠 및 게임 중 아이템·신발·스킬 후보
- 보유 장비·골드·상대 장비·아군 역할을 반영한 설명
- 소환사의 협곡 기준. 추천은 통계와 상황 규칙이며 승률 상승을 검증한 예측 모델이 아닙니다.

현재 릴리스와 변경 내용은 [릴리스 목록](https://github.com/Ohjjam/LoLPickCoach/releases)에서 확인하세요. 이 저장소는 실행 파일 배포용입니다.
